#🎯 Number Guessing Game in Python
A simple Number Guessing Game built using Python.
The computer randomly selects a number, and the player has to guess it correctly.

#🕹️ How the Game Works
The computer generates a random number.

The player enters a guess.

The game tells the player whether the guess is:

🔼 Too high

🔽 Too low

🎉 Correct

The game continues until the player guesses the correct number.

#🛠️ Technologies Used
🐍 Python

random module
